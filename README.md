# Netology-Final-Work

## Цель работы - создать простую модель, которая поможет предсказывать, уйдёт ли сотрудник из компании, и оценить, насколько такая модель работает на практике.

## Описание датасета:

Дан файл HR.csv с данными по опросу уровня удовлетворённости сотрудниками работой.

Признаки:

satisfaction_level — уровень удовлетворённости работой

Last_evaluation — время с момента последней оценки в годах

number_projects — количество проектов, выполненных за время работы

average_monthly_hours — среднее количество часов на рабочем месте в месяц

time_spend_company — стаж работы в компании в годах

work_accident — происходили ли несчастные случаи на рабочем месте с сотрудником

left — уволился ли сотрудник

promotion_last_5years— повышался ли сотрудник за последние пять лет

department — отдел, в котором работает сотрудник

salary — относительный уровень зарплаты

## EDA:

Были рассчитаны основные статистики для переменныз (среднее, медиана, мода, мин/макс, сред. отклонение). 

Рассчитана и визуализирована корреляционная матрица для количественных переменных.

## Гипотезы:

С помощью визуализаций, расчета статистик и проверки с помощью теста Бруеннера-Мунзеля, была отвергнута гипотеза о том, что сотрудники с высоким окладом проводят на работе больше времени чем сотрудники с низким окладом.

Для уволившихся и не уволившихся сотрудников были расчитаны следующие показатели: 1. Доля сотрудников с повышением за последние 5 лет 2. Средняя степень удовлетворенности 3.Среднее количество проектов.

По результатам расчетов получены следующие результаты: у уволившихся сотрудников в среднем был заметно меньший уровень удовлетворенности и доля повышений за 5 лет составляла 0.5%, у не уволившихся сотрудников был больший средний уровень удовлетворенности и доля повышений составляла 2.6%, среднее число проектов не сильно отличается, у обеих групп примерно 3.8 проектов в среднем.

## Построение модели LDA:

Была разделена выборка и построена модель LDA. 

Основной проблемой здесь выступил заметный дисбаланс классов; без устранения проблемы дисбаланса оценка точности модели методом score дает результаты = 0.76, однако на кросс-валидации точность заметно ниже = 0.33;

<img width="695" height="474" alt="image" src="https://github.com/user-attachments/assets/a20832a2-5808-4ae5-801e-d948e470d16f" />

Для решения этой проблемы использовались методы сэмплирования: RandomOverSampler и RandomUnderSampler.

Результаты с использованием RandomUnderSampler: score - 0.745, кросс-валидация - 0.746;
